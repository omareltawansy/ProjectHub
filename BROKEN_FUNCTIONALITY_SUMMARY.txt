PATTERN ANALYSIS

BROKEN PATTERN (Found in 8+ files):
  const { data: initialData } = useAppData();
  const [data, setData] = useState(initialData);
  
  setData(prev => [...prev, newItem]); // ❌ NOT SYNCED TO HOOK

CORRECT PATTERN (Should use):
  const { data, updateData, addData } = useAppData();
  
  addData(newItem);              // ✅ Auto-syncs to localStorage
  updateData(id, updates);       // ✅ Auto-syncs to localStorage
  updateDatas(newArray);         // ✅ Batch update with sync
